# Tagryn 0.1.0 — desktop alpha

Tagryn is an offline desktop workbench for inspecting, comparing, and deliberately editing file metadata. This first open source release invites contributions, including work made with AI.

## Download and install

These are **alpha preview installers**, available without a GitHub account. ExifTool and its private runtime are included; Node.js, Rust, and a separate Perl installation are not needed.

| Platform                                    | Download                                                                                                                                   | Install                                                                       |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| macOS 13.3+, Apple Silicon                  | [DMG for M-series Macs](https://github.com/franzgollhammer/tagryn/releases/download/v0.1.0-alpha.1/Tagryn_0.1.0-alpha.1_macos_arm64.dmg)   | Open the DMG, drag Tagryn to Applications, eject the DMG, then launch Tagryn. |
| macOS 13.3+, Intel                          | [App ZIP for Intel Macs](https://github.com/franzgollhammer/tagryn/releases/download/v0.1.0-alpha.1/Tagryn_0.1.0-alpha.1_macos_x64.zip)    | Extract the ZIP and drag **Tagryn.app** into **Applications**.                |
| Windows x64                                 | [Windows installer](https://github.com/franzgollhammer/tagryn/releases/download/v0.1.0-alpha.1/Tagryn_0.1.0-alpha.1_windows_x64-setup.exe) | Open the EXE, follow the installer, then launch Tagryn from Start.            |
| Ubuntu / compatible Debian-based Linux, x64 | [Debian package](https://github.com/franzgollhammer/tagryn/releases/download/v0.1.0-alpha.1/Tagryn_0.1.0-alpha.1_linux_amd64.deb)          | Use the commands below in the download folder.                                |

```sh
sudo apt update
sudo apt install ./Tagryn_0.1.0-alpha.1_linux_amd64.deb
tagryn
```

Linux package installation was checked on Ubuntu 22.04 x64. Other Debian-based distributions need compatible GTK/WebKitGTK libraries. RPM, AppImage, Flatpak, and Linux ARM packages are not included.

**First launch:** macOS packages are ad-hoc signed, **not Apple-notarized**. If you trust the download and macOS blocks it, use [System Settings → Privacy & Security → Open Anyway](https://support.apple.com/en-us/102445) after the first launch attempt. Windows installers are **unsigned**; SmartScreen may offer **More info → Run anyway** if you trust the download and device policy permits it. The Windows installer can download WebView2 if it is missing.

[SHA-256 checksums](https://github.com/franzgollhammer/tagryn/releases/download/v0.1.0-alpha.1/SHA256SUMS.txt) and [build provenance](https://github.com/franzgollhammer/tagryn/releases/download/v0.1.0-alpha.1/BUILD-INFO.json) accompany these installers. GitHub's additional “Source code” archives are for building the app yourself.

## Available now

- Native files and folders, recursive scans, virtualized lists and thumbnails, metadata search, and comparison of up to eight files.
- Explicit edit plans, allowlisted single and batch edits, keyword operations, time and GPS edits, and XMP sidecars.
- Verified backups, reread after saving, job history, and checked restoration.
- German and English interfaces, light and dark themes, adjustable text, keyboard navigation, and a command palette.
- Source, build instructions, contributor guidance, agent instructions, and a GitHub Actions verification matrix.

## Before you try it

This is an **alpha preview**, with installation and runtime checks on native GitHub runners. It is not a production release with verified publisher identity or acceptance on every end-user system. Application manifests use `0.1.0`; this prerelease is tagged `v0.1.0-alpha.1`.

Use disposable copies and keep independent backups. Tagryn performs real writes and does not promise complete anonymization. Original metadata may remain in backups, caches, history, and exports. Format support is deliberately limited; GPX matching, online maps, automatic updates, live filesystem watching, and embedded audio/video/PDF writes are not implemented.

See [format limits](https://github.com/franzgollhammer/tagryn/blob/v0.1.0-alpha.1/docs/FORMATS.md) and [data integrity](https://github.com/franzgollhammer/tagryn/blob/v0.1.0-alpha.1/docs/SAFETY.md).

## Verification

Application commit `9998760f296047fb1335dee08533416aa9b4eb14` passed [the complete application matrix](https://github.com/franzgollhammer/tagryn/actions/runs/34597693265) on September 11, 2026: Rust and Node suites, runtime verification, the metadata smoke session, Playwright checks, and package builds on all four native targets. The existing release tag still points to that commit.

[Native packaging verification](https://github.com/franzgollhammer/tagryn/actions/runs/34609674849) passed all four targets on September 11, 2026, using packaging commit `64e15e91fa0efa99269e43e6e92901184429754b`. The packaging workflow checks source artifact hashes and provenance, installation, DMG copying, or app ZIP extraction, included license notices, the private metadata runtime, and installed frontend readiness. Runtime checks use synthetic Unicode-named media, verify metadata read/write and exact fixture backup restoration, and hide external tools from PATH. These runtime probes complement the application's existing integrity tests; they do not simulate every user workflow or end-user machine.

The macOS bundles receive complete ad-hoc signatures and omit optional Perl DBM bindings that could depend on Homebrew libraries; ExifTool does not use these modules. Windows EXE and Linux DEB bytes are preserved from the original verified build. Individual hashes and build identities are recorded in `BUILD-INFO.json`.
