# Tagryn 0.1.0 — source alpha

Tagryn is an offline desktop workbench for inspecting, comparing, and deliberately editing file metadata. This first open source release invites contributions, including work made with AI.

## Available now

- Native files and folders, recursive scans, virtualized lists and thumbnails, metadata search, and comparison of up to eight files.
- Explicit edit plans, allowlisted single and batch edits, keyword operations, time and GPS edits, and XMP sidecars.
- Verified backups, reread after saving, job history, and checked restoration.
- German and English interfaces, light and dark themes, adjustable text, keyboard navigation, and a command palette.
- Source, build instructions, contributor guidance, agent instructions, and a GitHub Actions verification matrix.

## Before you try it

This is a **source alpha**, not a supported installer release. Build requirements and commands are in the README. No signed or notarized installers are attached. Application manifests use `0.1.0`; this prerelease is tagged `v0.1.0-alpha.1`.

Use disposable copies and keep independent backups. Tagryn performs real writes and does not promise complete anonymization. Original metadata may remain in backups, caches, history, and exports. Format support is deliberately limited; GPX matching, online maps, automatic updates, live filesystem watching, and embedded audio/video/PDF writes are not implemented.

See [format limits](https://github.com/franzgollhammer/tagryn/blob/v0.1.0-alpha.1/docs/FORMATS.md), [data integrity](https://github.com/franzgollhammer/tagryn/blob/v0.1.0-alpha.1/docs/SAFETY.md), and [verification runs](https://github.com/franzgollhammer/tagryn/actions/workflows/verify.yml). A configured workflow alone is not a passing cross-platform check. Release publication should append the actual run URL and conclusion.

## Contribute

Start with [CONTRIBUTING.md](https://github.com/franzgollhammer/tagryn/blob/v0.1.0-alpha.1/CONTRIBUTING.md) and the [roadmap](https://github.com/franzgollhammer/tagryn/blob/v0.1.0-alpha.1/docs/ROADMAP.md). Small bug fixes, English documentation, accessibility checks, and synthetic format fixtures are useful starting points. AI assistance is welcome; submitters remain responsible for understanding and verifying their changes.
