# Reporting security issues

Report vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/franzgollhammer/tagryn/security/advisories/new). Include the affected version or commit, operating system, reproduction steps, expected behavior, and observed impact. Use synthetic media or a minimized sample you have permission to share.

Do not put exploitable vulnerabilities, private media, credentials, GPS coordinates, or personal metadata in public issues. For ordinary bugs with no sensitive details, use the issue tracker. A data-loss bug may be reported publicly with a synthetic reproduction; use private reporting if it also enables unauthorized access or exposes private data.

Tagryn is an early project without a guaranteed response time or long-term support branches. Fixes initially target `develop` and the next release. Use [SAFETY.md](docs/SAFETY.md) for the current integrity guarantees and limitations. Metadata removal does not promise complete anonymization, and backups can retain the original values.
